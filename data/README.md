# Data

This project uses a fully self-collected dataset. No external datasets are required.

## Folder Structure

After running the data collection pipeline, your `data/custom/` directory should look like this:

```
data/custom/
├── images/          ← full resolution webcam frames (640x480)
├── labels/          ← YOLO format annotation files (one per image, with digit class IDs)
├── crops/           ← cropped hand images organised by digit class
│   ├── 0/
│   ├── 1/
│   ├── 2/
│   ├── 3/
│   ├── 4/
│   ├── 5/
│   ├── unlabelled/  ← crops awaiting class assignment
│   └── unclear/     ← crops that couldn't be confidently classified
├── excluded/        ← frames where annotation and crop counts didn't match
│   ├── images/
│   └── labels/
└── detection.tfrecord  ← generated by create_tfrecords.py
```

## Collection Pipeline

Data collection is split into five steps. Run `capture.py` first — it creates all required folders automatically.

---

**Step 1 — Capture frames**
```bash
python src/data/capture.py
```
Records webcam frames following a guided sequence. Press `f` to freeze immediately or `t` for a 3-second countdown (useful for getting both hands in frame). Saves raw frames to `data/custom/images/`.

---

**Step 2 — Annotate bounding boxes**
```bash
python src/data/annotate_boxes.py
```
Opens each unannotated image. Press `b` to draw a bounding box around a hand, repeat for additional hands, then press `d` when done with that image. Saves YOLO format `.txt` annotation files to `data/custom/labels/` and saves raw crops to `data/custom/crops/unlabelled/`. Press `q` to quit and resume later — already annotated images are skipped automatically.

---

**Step 3 — Label crops**
```bash
python src/data/label_crops.py
```
Opens each unlabelled crop from `crops/unlabelled/`. Press `0`–`5` to assign the digit class and move the crop to the corresponding `crops/N/` folder. Press `u` for unclear images. Press `q` to quit and resume later.

---

**Step 4 — Propagate class labels to annotations**
```bash
python src/data/classify_boxes.py
```
Matches each labelled crop back to its source annotation file using the frame number encoded in the crop filename, then rewrites the annotation files to include the correct digit class ID for each bounding box. Frames where the crop count doesn't match the annotation line count are moved to `excluded/` and logged. Successfully classified frames are kept in `images/` and `labels/`.

---

**Step 5 — Generate TFRecord**
```bash
python src/data/create_tfrecords.py
```
Reads all annotated images from `data/custom/images/`, applies preprocessing, and writes `data/custom/detection.tfrecord` for training. Then you can use train_detector.py for training.

---

## Notes

- Collect images across multiple locations and lighting conditions for better generalisation
- Include ~10–15% negative examples (frames with no hands) to reduce false positives — press `d` immediately without drawing any boxes in `annotate_boxes.py`
- The `excluded/` folder contains frames where annotation and crop counts didn't match — these can be re-annotated manually if needed
